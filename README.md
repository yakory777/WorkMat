## 👋 О репозитории

Здесь собраны рабочие материалы, которые я использую на занятиях: презентации к урокам, задания, примеры моделей, шпаргалки и всё, что помогает разобраться в 3D-моделировании и промышленном дизайне.

Репозиторий задуман как **открытая копилка**: ученики могут скачать материалы урока, повторить пройденное или забежать вперёд, а коллеги — взять что-то в свою работу.

> 💡 Если вы ученик и пропустили занятие — найдите нужную тему в разделе ниже, там есть всё, чтобы догнать группу.

## 🚀 Как пользоваться

**Самый простой способ — скачать всё сразу:**

1. Нажмите зелёную кнопку **`Code`** вверху страницы.
2. Выберите **`Download ZIP`**.
3. Распакуйте архив — готово!

**Нужен только один файл?** Откройте его и нажмите кнопку **скачивания** (⬇️) справа над содержимым.

**Для тех, кто знаком с Git:**

```bash
git clone https://github.com/ВАШ_НИК/НАЗВАНИЕ_РЕПОЗИТОРИЯ.git
```

А чтобы получить свежие материалы позже:

```bash
git pull
```

## 🧭 С чего начать новичку

1. 🟢 Загляните в `3d-modeling/01-intro` — там основы и первая модель.
2. 🟡 Пройдите задания из `assignments/` начального уровня.
3. 🔴 Попробуйте свой мини-проект — идеи есть в `industrial-design/`.

Не бойтесь ошибаться: каждая неудачная модель — это шаг к удачной 🙂
